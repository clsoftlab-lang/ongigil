# 온기길 (Ongigil) — 따뜻한 길

**이웃이 조용히 누군가의 하루를 돕습니다. "여기 폐지 있어요" 한 번 눌러 알려 주면,
그것을 주워 생계를 잇는 어르신이 화면을 보지 않고도 귀로 길을 안내받습니다.**

온기길은 손수레로 **폐지·박스를 모아 생계를 잇는 어르신**을 돕는, 무료이자 공개된 공익 서비스입니다.
시민과 가게가 재활용 폐지가 나온 곳을 **GPS로 한 번 탭**하여 알려 주면, 어르신은 가장 가까운 곳까지
**손을 쓰지 않고 음성으로** 안내받습니다 — 방향과 거리를, 걷는 동안 조용히 반복해서 말해 줍니다.

> 돈이 오가지 않습니다. 광고 없음, 데이터 판매 없음. 그저 이웃이 작은 정보를 나누는 일입니다.

## 누구를 위한 것인가 — 눈이 아니라 귀로

이 서비스가 돕는 분들은 대개 **70~80대**로, 적은 벌이를 위해 하루 종일 걸으시고, 눈이 침침하시거나
스마트폰이 익숙지 않으실 수 있습니다. 그래서 모든 설계를 그분들께 맞춥니다.

- **눈이 아니라 귀로.** 어르신은 오직 **음성**만으로 안내받을 수 있습니다 — "북동쪽 80 m, 가까워지고
  있어요… 바로 앞이에요" — 수레를 밀면서 손을 쓰지 않고요. 화면은 보지 않아도 됩니다.
- **큰 버튼 하나.** 어르신 화면은 큰 글씨와 버튼 하나뿐입니다 — **"안내 시작"**. 계정도, 헤맬 메뉴도
  없습니다.
- **동정이 아니라 따뜻함.** 이 일은 생계와 존엄을 돕는 일입니다. 모든 문구는 정중하고, 쉽고,
  따뜻하게 씁니다.

알려 주는 일은 시민이, 받는 일은 어르신이 — 그것이 이 서비스의 핵심입니다.

## 어떻게 작동하나요

```
  알리는 사람 (시민 / 가게)                     받는 사람 (어르신, 손을 안 씀)
  ────────────────────────                     ──────────────────────────────
  폐지가 나온 걸 봄                              큰 버튼 하나를 누름: "안내 시작"
  "여기 폐지 있어요" 탭  ──►  지점 저장  ──►      가장 가까운 곳들을 찾아
  (GPS 한 번, 대략 위치)                          걷는 내내 음성으로 말해 줌:
  선택: 양·종류·언제까지                            "북동쪽 80 m, 가까워지고 있어요"
        │                                           "50 m … 20 m … 앞에 있습니다"
        ▼                                         도착 → "도착했어요"
   지점이 지도에 잠깐 뜸                           → "가져갔어요 / 여기 없어요" 표시
    (몇 시간 뒤 스스로 사라짐)                       (정보를 정직하게 유지)
```

알리는 분이 한 번 탭하면 지점이 잠깐 생겼다가, **몇 시간 뒤 스스로 사라집니다.** 그래서 어르신이
이미 없어진 폐지를 향해 헛걸음하지 않습니다. 어르신은 한 번 누르고 **그저 음성을 따라** 걸으시면 됩니다.
도착하시면 "가져갔어요 / 여기 없어요"를 눌러 다음 분을 위해 정보를 정직하게 남길 수 있습니다.

## 지금 바로 체험 (열쇠 불필요)

앱은 브라우저 안에서 **데모 모드**로 완전히 동작합니다 — 미리 넣어 둔 지점과 걷는 흉내(시뮬레이션) —
그래서 서버도 어떤 열쇠(API 키)도 없이 **음성 안내를 직접 듣고 볼 수 있습니다.**

- **온라인 데모:** `https://clsoftlab-lang.github.io/ongigil/app/`
  *(운영자가 저장소의 GitHub Pages를 켜면 접속됩니다. 그전까지는 아래처럼 내 컴퓨터에서 실행하세요.)*
- **내 컴퓨터에서:** `app/` 폴더를 HTTP로 띄워서 여세요 — [개발자 빠른 시작](#개발자-빠른-시작) 참고.

소리를 켜고 **"안내 시작"**을 누르면, 걷는 흉내가 미리 넣어 둔 지점으로 데려갑니다. 방향, 줄어드는
거리, 그리고 "가까워져요 / 멀어져요"를 들을 수 있습니다.

## 지금 갖춰진 것 vs 나중에 더할 것

| 영역 | 상태 | 설명 |
|---|---|---|
| PWA 앱 (받는 사람 / 알리는 사람 / 도우미) | ✅ 완성 | 빌드 단계 없음, 열쇠 없이 데모 모드로 동작 |
| 백엔드 API (알림·주변·피드백·만료) | ✅ 완성 | 작은 FastAPI + SQLite, 열쇠 없이 동작 |
| 호밍 음성 안내 (GPS + 나침반) | ✅ 완성 | 방향+거리를 말하고 반복, 지도 API 불필요 |
| 위치 뭉개기 / 프라이버시 | ✅ 완성 | 공유 위치는 대략적, 정확 좌표는 서버에만 |
| 지점 알림·자동 만료 | ✅ 완성 | 지점이 스스로 사라져 목록이 최신, "가져감/없음" 피드백 |
| **화면 끈 상태 음성용 네이티브 앱** | ⚠️ 나중에 | 웹앱은 화면을 끄면 안정적으로 말하지 못함 — 안드로이드 앱 필요 ([이유](#정직한-한계-화면-끔)) |
| **정밀 턴바이턴 길안내** | ⚠️ 나중에 | 선택: 운영자가 보행 길안내 제공자 열쇠 추가. 호밍 모드는 열쇠 없이 항상 동작 |
| **실제 호스팅 / HTTPS** | ⚠️ 나중에 | 운영자가 API를 배포하고 HTTPS·GitHub Pages를 켬 |
| **지역사회 홍보** | ⚠️ 나중에 | 어르신·복지관·사회복지사에게 알리기 — 아래 참고 |

## 🕊️ 프라이버시와 존엄

- **위치는 대략만.** 알린 지점은 공유되기 전에 **뭉개집니다**(반올림 / 구역 단위로 스냅). 정확한
  좌표는 서버에만 남고 다른 사용자에게 **절대 보이지 않습니다.**
- **알리는 사람은 익명.** 이름·얼굴·집 주소 없이 알릴 수 있습니다.
- **어르신은 추적하지 않습니다.** 안내에 쓰이는 위치는 그 순간 폰에서만 쓰이고 오래 저장하지
  않습니다. 내 데이터는 **내보내거나 삭제**할 수 있습니다.
- **모든 문구는 정중하게.** 생계를 돕는 일이므로, 결코 동정으로 그리지 않습니다.
- **아무것도 팔거나** 제3자와 공유하지 않습니다. 광고도 없습니다.

자세히: [docs/ko/04-프라이버시와존엄.md](docs/ko/04-프라이버시와존엄.md)

## ⚠️ 안전

- 안내는 **참고용입니다.** 차량을 살피시고, 폐지를 위해 길을 급히 건너지 마세요.
- **야간·이른 아침 주의** 안내가 표시되며, 번잡한 도로변 지점은 숨길 수 있습니다.
- 어떤 지점도 사유지나 위험한 곳으로 이끌지 않도록 — 위험한 지점을 신고하는 버튼이 있습니다.
- 크고 대비 높은 글씨, 쉬운 말, 그리고 언제나 보이는 큰 **"그만"** 버튼.

자세히: [docs/ko/05-접근성.md](docs/ko/05-접근성.md)

## 정직한 한계 (화면 끔)

이일국 박사님의 바람은 자동차 내비게이션처럼 **화면을 끈 채로** 안내받는 것입니다. 솔직히 말씀드립니다.
**웹앱(PWA)은 화면을 완전히 끄거나 다른 앱을 쓰는 동안에는 안정적으로 말하지 못합니다** — 브라우저가
배터리를 아끼려고 타이머·위치·음성을 멈추기 때문입니다.

그래서 **v0.1은 안내 중 화면을 켜 둡니다**(Wake Lock 사용) 그리고 이 점을 **분명히 알립니다.** 또한
주머니 속 폰에서도 들리도록 문장을 짧게 유지합니다. **화면을 끈 채로 하는 진짜 배경 음성 내비게이션은
안드로이드 네이티브 앱이 필요합니다** — 이것이 다음 단계입니다. 웹앱이 그 이상을 하는 척하지 않습니다.

자세히: [docs/ko/06-배포와한계.md](docs/ko/06-배포와한계.md)

## 음성 안내, 쉽게 설명하면

기본 모드는 지도가 필요 없습니다. 폰은 이미 두 가지를 압니다 — **지금 어디인지**(GPS)와 대개
**어느 쪽을 보고 있는지**(나침반). 이로부터 앱이 계산합니다.

- **어느 쪽인지** — 쉬운 말로: "북동쪽", 나침반이 있으면 방향 지시로: "오른쪽으로 도세요", "왼쪽 앞으로".
- **얼마나 먼지** — 적절할 때 말하고 마지막엔 세어 줍니다: "50 m … 30 m … 20 m … 앞에 있습니다."
- **더 가까운지 먼지** — "가까워지고 있어요 / 멀어지고 있어요" — 나침반이 **없는** 폰도 방향을
  옳게 잡았는지 알 수 있습니다.
- **도착** — "거의 다 왔어요" 다음 "도착했어요", 그리고 가져감/없음을 표시.

나중에 정밀 보행 길안내 열쇠를 더하면 거리 단위 턴바이턴으로 바꿀 수 있지만, 무료 호밍 모드는
언제나 동작합니다. 자세히: [docs/ko/03-음성안내.md](docs/ko/03-음성안내.md)

## 지역사회·사회복지사를 위하여

꼭 어르신 본인이 아니어도 됩니다. 가족, 사회복지사, 복지관 직원이 **도우미**가 될 수 있습니다 —
대신 지점을 알려 주거나, 어르신 폰을 한 번만 설정해(음성 언어, 말하기 속도, 큰 글씨) 이후로는 버튼
하나만 누르고 듣게 해 드릴 수 있습니다.

복지관이나 단체에서 돌보시는 분들과 온기길을 함께 써 보고 싶으시거나, 실제 어르신들과 함께 시험해
주실 수 있다면 정말 반갑겠습니다. [GitHub 이슈](../../issues/new/choose)의 **지역사회 협력 문의**를
열거나 [토론(Discussions)](../../discussions)을 시작해 주세요. 비용도, 조건도 없습니다 — 공익 사업입니다.

## 개발자 빠른 시작

**백엔드 — API (열쇠 불필요):**

```bash
cd backend
pip install -e ".[dev]"
# API 실행 (진입점은 backend/README.md 채워지는 대로), 예:
uvicorn ongigil.main:app --reload
```

**앱 — 데모 (빌드 없음, 열쇠 없음):**

```bash
# 저장소 루트에서
python -m http.server 8150 --directory app
# http://localhost:8150/ 열기 → 데모 모드: 미리 넣은 지점 + 걷는 흉내를 소리로 체험
```

Claude Code 미리보기(`.claude/launch.json`, 이름 `ongigil-app`, 포트 8150)로도 열 수 있습니다.
앱은 번들러·외부 CDN 없는 순수 HTML/JS 모듈이라 어떤 정적 서버로도 동작합니다. 안내를 단계별로
들으려면 [docs/ko/01-빠른시작.md](docs/ko/01-빠른시작.md) 참고.
