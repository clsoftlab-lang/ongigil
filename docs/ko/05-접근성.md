# 05 · 접근성 — 어르신 우선 설계

사용자는 흔히 **70~80대**이고, 하루 종일 걸으시며, 눈이 침침하시거나 스마트폰이 익숙지 않으실 수
있습니다. 여기서 접근성은 마지막에 덧붙이는 점검표가 아니라 **설계 그 자체**입니다. 모든 것을 그분들께
맞춥니다(설계서 §1, §7).

한 가지 규칙: **눈이 아니라 귀로.** 어르신이 눈을 전혀 쓸 수 없어도 폐지까지 안내받을 수 있어야 합니다.
화면은 필수가 아니라 덤입니다.

---

## 실제로 한 것

| 원칙 | 앱에서 |
|---|---|
| **음성 우선** | 방향+거리를 **말하고** 반복 — 어르신이 귀로 손 안 쓰고 일함 ([03 · 음성 안내](03-음성안내.md)) |
| **큰 버튼 하나** | 받는 사람 주 화면은 큰 **"안내 시작"** 버튼 하나 — 헤맬 메뉴 없음 |
| **큰 글씨** | 크고 대비 높은 글씨, 설정에서 글씨 크기 조절 |
| **높은 대비** | 강한 전경/배경 대비, 회색 위 회색 없음 |
| **큰 터치 영역** | 큰 줄과 버튼, 넉넉한 간격 — 부정확한 탭도 쉬움 |
| **쉬운 말** | 짧고 쉬운 한국어, 전문용어·영어전용 라벨 없음 |
| **항상 보이는 "그만"** | 안내 내내 큰 **그만** 버튼 |
| **차분한 음성** | 짧은 문장, 속도 조절, 음소거·다시 듣기 — 말의 벽 없음 |
| **도우미 설정** | 가족·사회복지사가 음성·속도·글씨를 **한 번** 잡아 주면 어르신은 버튼 하나만 |
| **적은 권한** | 위치만으로 동작, 나침반·Wake Lock은 없으면 우아하게 낮춤 |
| **음성 없음 대비** | 원하는 음성이 없어도 침묵하지 않고 기본 음성으로 말함 |

## 화면, 단순하게

- **받는 사람:** 큰 "안내 시작" → 가장 가까운 지점 짧은 목록(큰 줄: 방향 화살표, 거리, "안내") →
  **안내 화면**(큰 화살표+거리, 큰 **도착 / 여기 없어요 / 그만** 버튼, 음성 내내, "화면을 켜 두세요" 상시
  안내). "가까운 곳 소리로" 빠른 동작은 가장 가까운 지점을 즉시 읽어 줌.
- **알리는 사람:** 한 화면 — 큰 **"여기 폐지 있어요"** 버튼, 선택 칩(양 적음/보통/많음, 종류, 언제까지),
  따뜻한 확인.
- **도우미:** 대신 알림, 어르신 설정, 간단한 사용법.

## 실제 사용자와 시험하는 법

접근성은 가정이 아니라 사람으로 증명합니다. 존중을 담은 권장 절차:

1. **복지관이나 신뢰가 있는 사회복지사를 통해 모집** — 취약한 어르신께 무작정 다가가지 마세요.
   (README의 "지역사회·사회복지사를 위하여" 참고.)
2. **쉽게 설명하고 동의를 받기**: 무엇을 하는지, 무료라는 것, 추적·판매가 없다는 것, 언제든 멈출 수
   있다는 것.
3. **먼저 버튼 하나 경로를 관찰.** 화면을 **보지 않고** 안내를 시작해 음성을 따라갈 수 있나요? 어디서
   망설이는지 봅니다.
4. **함께 음성을 듣기.** 충분히 크고, 느리고, 차분한가요? 속도를 조절하고 헷갈리는 문구를 적습니다.
5. **글씨와 대비 확인** — 실제 낮과 밤, 팔 길이 거리에서, 본인 시력으로.
6. **짧은 실제 경로를 안전하게 동행하며 걷기** — "가까워짐/멀어짐" 신호가 걸을 때 말이 되는지 확인.
7. **접근성 피드백으로 기록** — [접근성 피드백 이슈](../../issues/new/choose)를 엽니다. 칭찬만이 아니라
   불편을 적습니다.

존엄을 지키며 하세요: 어르신은 자신의 하루에 관한 전문가입니다. 우리는 어르신이 아니라 앱을 시험합니다.

  앱이 길입니다 ([06 · 배포와 한계](06-배포와한계.md)).

- 다국어 음성과 더 깊은 복지관 도구는 예정입니다(설계서 §10, P2).
