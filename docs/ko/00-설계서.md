# 온기길 (Ongigil) — 손수레 수거 어르신을 위한 재활용 폐지 찾기 — 설계서 (v0.1)

> **상태:** 참조 설계 + 동작하는 웹앱(v0.1). 이 문서가 유일한 기준 문서입니다.
> 앱·API·안내서는 이 문서를 따릅니다. 먼저 이 문서를 바꾸고, 그다음 코드를 바꾸세요.

- 프로젝트: **온기길 (Ongigil)** — "따뜻한 길". **재활용 폐지·박스를 모아** 생계를 잇는 어르신이 그것이
  어디 나왔는지 찾도록 돕는, 무료 공익 서비스. **시민과 가게가** "여기 폐지 있어요"를 한 번의 탭(GPS)으로
  알리면, 어르신은 **손을 쓰지 않는 음성 안내**를 받습니다 — "북동쪽 80 m에 폐지, 가까워지고 있어요…
  바로 앞이에요" — 그래서 화면을 응시하지 않고 수레를 밀며 귀로 따라갈 수 있습니다.
- 돈이 오가지 않습니다. 공익을 위한 순수한 정보 나눔입니다.
- 프로젝트 리드: **CLSOFTLAB (씨엘소프트랩), 이일국 박사**. 기여자: LWJ, LMJ.
- Claude(Anthropic의 AI)와 함께 설계. Anthropic의 제품이 아님.
- 라이선스: 소프트웨어 Apache-2.0 · 문서 CC BY 4.0.

## 1. 누구를 위한 것이며, 하나의 설계 규칙

사용자는 **손수레 수거 어르신** — 흔히 70~80대, 적은 수입을 위해 하루 종일 걷고, 눈이 좋지 않을 수
있으며, 스마트폰이 늘 편하지는 않습니다. **모든 것이 그분들께 맞춰집니다:**

| # | 원칙 | 결과 |
|---|---|---|
| O1 | **눈이 아니라 귀로** | 어르신은 오직 **음성**으로 안내받을 수 있음 — 수레를 밀며 손 없이, 방향+거리를 말하고 반복("북동쪽, 80 m, 가까워지고 있어요"). 화면은 선택. |
| O2 | **큰 버튼 하나** | 받는 사람 화면은 큰 글씨 + 버튼 하나("가장 가까운 곳으로 안내"). 계정 없음, 헤맬 메뉴 없음. |
| O3 | **열쇠도 지도 서비스도 없이 동작** | 기본 안내는 폰의 GPS + 나침반만 사용(호밍 방향 + 거리)하여 **유료 지도 API 없이** 어디서나 동작. 정밀 턴바이턴은 운영자가 나중에 더할 선택 업그레이드(§5). |
| O4 | **친절한 이웃이 데이터를 제공** | 시민과 가게가 폐지 나온 곳을 알림(A-모델). 어르신은 대개 **받음**. |
| O5 | **안전 최우선** | 도로변·야간 경고; 결코 위험한 행동으로 몰지 않음; 안내는 참고용. |
| O6 | **프라이버시와 존엄** | 알린 위치는 **대략** 표시; 얼굴·정확한 집 주소 없음; 어르신 추적 없음; 판매 없음. 문구에서 모두를 존중. |
| O7 | **한계에 정직** | 웹앱은 화면을 완전히 끈 채 안정적으로 말하지 못함(§6). 화면을 켜 두고 그렇게 밝힘; 진짜 화면 끔은 나중에 네이티브 앱 필요. |
| O8 | **무료·공개** | 결제·광고·데이터 판매 없음. Apache-2.0 / CC-BY만. |

## 2. 순환 고리

```
 알리는 사람 (시민 / 가게)                     받는 사람 (어르신, 손 안 씀)
 ────────────────────────                     ──────────────────────────────
 폐지가 나온 걸 봄                              큰 버튼 하나를 누름: "안내 시작"
 "여기 폐지 있어요" 탭  ──► 지점 저장    ──►    앱이 가장 가까운 열린 지점을 찾고,
 (GPS, 대략; 선택: 종류/양,                       걸으면서 계속 말함:
  "많음", "6시까지")                              "북동쪽 80 m, 가까워지고 있어요"
        │                                          "50 m … 20 m … 앞에 있습니다"
        ▼                                        도착 → "도착했어요" → 가져감 / 없음 표시
   지점이 지도에 살아 있음                         (지점은 만료되어 목록이 신선하게 유지)
```

알림은 자동으로 만료됩니다(기본 몇 시간, 설정 가능) — 그래서 어르신이 이미 사라진 폐지로 안내받지
않습니다. 어르신은 지점을 "가져감" 또는 "없음"으로 표시해 데이터를 정직하게 유지할 수 있습니다.

## 3. 역할, 데이터, 화면

**역할:** 알리는 사람(시민/가게 — 익명, 한 번 탭), 받는 사람(어르신 — 안내를 받음), 도우미(대신 알리거나
설정해 주는 가족/사회복지사/복지관 직원), 관리자/모더레이터. 알리거나 안내받는 데 로그인 불필요; 선택적
가벼운 프로필만.

**엔티티:**
- `Spot {id, geoApprox, exactGeoPrivate(서버 측, 공유 전 뭉갬), kind(paper|cardboard|mixed),
  size(small|medium|large), note, status(open|taken|gone|expired), reportedAt, expiresAt, reporterRef(익명)}`
- `GuidanceSession {collectorRef?, targetSpotId, startedAt, lastPos, events[]}` (일시적; 장기 저장 안 함)
- `Report/Feedback {spotId, kind(taken|not_there|report_bad), at}`
- 최소 `User {id, role, ageBand?, prefs(voiceLang, speechRate, units), createdAt}` — 선택.

**화면:**
- **받는 사람(기본, 아주 큰 UI):** 큰 "안내 시작" 버튼 → 가장 가까운 지점 목록(큰 줄: 방향 화살표, 거리,
  "안내") → **안내 화면**(큰 화살표 + 거리, 큰 "도착/여기 없어요/그만" 버튼; 음성 내내; "화면을 켜 두세요"
  상시 안내). "가까운 곳 소리로" 빠른 동작.
- **알리는 사람:** 한 화면 — GPS를 잡는 큰 "여기 폐지 있어요" 버튼; 선택 칩(양 적음/보통/많음, 종류,
  언제까지); 확인; "고맙습니다"(누군가의 하루에 힘이 됩니다).
- **도우미:** 대신 알림; 어르신 설정(음성 속도, 언어); 간단한 사용법.
- **설정:** 음성 언어(기본 ko, en), 말하기 속도, 단위(m), 화면 켜 두기, 글씨 크기, 데이터 내보내기/삭제,
  지도 업그레이드 안내.
- **도움말 / 안전 / 소개.**

## 4. 음성 안내 (핵심) — 무료 "호밍" 모드

기본 모드는 **지도 API가 필요 없습니다:** 브라우저의 Geolocation(위치)과, 가능한 곳에선 Device
Orientation(나침반 방위)만. 앱이 대상까지의 방위 + 거리를 계산해 말하고, 어르신이 움직이면 반복합니다.

- **방위 → 말:** 방위를 사용자 언어의 8방위로 변환("북동쪽"), 나침반 방위를 알 수 있으면 상대 회전으로도
  변환("오른쪽으로 도세요", "왼쪽 앞으로") — 이일국 박사님이 바라신 "왼쪽 10 m / 오른쪽 10 m" 느낌을
  방위+방위각으로, 지도 없이.
- **거리 신호:** 적절한 임계값에서 말함(예: 약 20 m 변화마다, 50 m 미만 카운트다운: "50 m … 30 m …
  20 m … 앞에 있습니다"), "가까워지고 있어요 / 멀어지고 있어요"와 함께 — 나침반 없는 어르신도 방향을
  옳게 잡았는지 알 수 있음.
- **도착:** 약 15 m 이내 → "거의 다 왔어요", 약 8 m 이내 → "도착했어요" → 가져감/없음 표시.
- **음성:** Web Speech API `speechSynthesis`, 한국어 음성, 속도 조절; 짧고 차분하고 정중한 문장; 말의
  벽 금지; 음소거/다시 듣기 버튼.
- **나침반 없음?** (많은 폰/iOS는 권한 필요, 일부는 없음) → 움직임 기반 방위로 대체: 걷는 동안 연속 GPS
  점에서 방향 추정; 여전히 방향 + "가까워짐/멀어짐"을 말함.
- **선택적 정밀 턴바이턴(업그레이드, §5):** 운영자가 보행 길안내 제공자 열쇠를 더하면 거리 턴바이턴으로
  전환 가능. 기본은 꺼짐; 무료 호밍 모드는 항상 동작.

## 5. 지도 / 길안내 — 열쇠는 나중에(운영자)

- `Directions` 인터페이스: `route(from, to) -> steps[]`. **HomingDirections** 구현(나침반/GPS, 열쇠
  없음, 기본)과 실제 제공자용 **스텁**(카카오/네이버/구글 보행 API)과 함께 제공.
- 제공자 열쇠는 **환경변수/설정 전용**, 나중에 운영하는 사람이 넣음 — 이 저장소는 **열쇠가 필요 없고**
  호밍 모드로 완전히 동작. 어떤 열쇠나 비밀도 커밋하지 않음.

## 6. 화면 끔 / 백그라운드 — 정직한 한계

- 이일국 박사님의 목표는 자동차 내비게이션처럼 화면을 끈 채 안내받는 것. **웹앱(PWA)은 화면을 완전히
  끄거나 백그라운드에서 안정적으로 말하지 못함** — 브라우저가 타이머·위치·음성을 멈춤.
- 그래서 v0.1은 **Wake Lock**으로 안내 중 화면을 켜 두고 그 점을 분명히 밝히며, 주머니 속 폰에서도
  들리도록 문장을 짧게 유지. **진짜 화면 끔, 백그라운드 음성 내비게이션은 안드로이드 네이티브 앱이
  필요**(다음 단계로 문서화). 웹앱이 그 이상을 하는 척하지 않음.

## 7. 안전

- 안내는 참고용; 차량을 살피고 결코 급히 도로를 건너지 말라고 안내.
- 야간/이른 아침 주의 안내; 선택적 "번잡한 도로변 지점 숨기기".
- 어떤 지점도 사유지나 위험으로 이끌면 안 됨; 위험 지점 신고 버튼.
- 크고 대비 높은 글씨; 쉬운 말; 항상 보이는 큰 "그만".

## 8. 프라이버시와 존엄

- 알림은 공유용으로 **대략** 위치를 저장(뭉갬, 예: 반올림 / 구역 스냅); 정확 좌표는 서버에만 남고 다른
  사용자에게 절대 안 보임.
- 얼굴·이름·정확한 집 주소 불필요. 알리는 사람은 익명.
- 어르신은 **추적하지 않음:** 안내 위치는 실시간으로 쓰이고 장기 저장 안 함; 내보내기/삭제 가능.
- 모든 문구는 존중하고 따뜻하게 — 생계와 존엄을 돕는 일이며, 결코 동정으로 그리지 않음.
- 아무것도 팔거나 제3자와 공유하지 않음. 광고 없음.

## 9. 아키텍처

```
 PWA (설치형; 받는 사람 / 알리는 사람 / 도우미 모드)  ──HTTPS──►  API (작고 상태 없음)
   Geolocation + DeviceOrientation (나침반)                       지점 (알림, 주변, 만료)
   speechSynthesis (한국어 음성)                                  피드백 (가져감/없음/부적절)
   Wake Lock (안내 중 화면 켬)                                    Directions(호밍 기본 | 제공자 스텁)
   선택한 지점 안내는 오프라인 동작                               저장: 지점 (SQLite), 뭉개기
```

- **프론트엔드:** PWA, 빌드 단계 없음, 순수 JS + 모듈, 외부 CDN 없음; 아주 큰 접근성 UI; 한국어 우선.
- **백엔드:** 작은 파이썬(FastAPI) API, SQLite; 알림/주변/피드백/만료; 위치 뭉개기; `Directions`
  인터페이스(호밍 기본, 제공자 스텁). **열쇠 없이** 동작.
- **데모 모드:** 앱이 미리 넣은 지점과 걷는 흉내로 완전히 클라이언트 측 동작 — 링크로 음성 안내를 들을 수
  있음, 백엔드·열쇠 없음.

## 10. 단계

| 단계 | 범위 |
|---|---|
| P0 | 동작하는 데모: 지점 알림 → 어르신이 호밍 음성 안내를 들음(걷는 흉내), 전부 브라우저 안 |
| P1 | 백엔드: 실제 알림, 주변 조회, 만료, 피드백, 뭉개기; PWA 연결; Wake Lock; 도우미 모드 |
| P2 | 지역사회 확산 지원: 다국어 음성, 복지관/도우미 도구, 실제 어르신과 접근성 검토 |
| P3 | 진짜 화면 끔 백그라운드 음성 내비게이션용 안드로이드 네이티브 앱; 선택적 정밀 턴바이턴(운영자 열쇠) |

## 11. 이름

작업 제목 **온기길 (Ongigil, "따뜻한 길")**. 대안: **모아 (Moa)**, **온기지도**, **줍고**, **이음길**,
**손수레**. 최종 이름은 운영자가 선택; 한 줄 변경으로 끝남.
