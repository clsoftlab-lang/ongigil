# 02 · 데이터 모델 — 엔티티와 생애주기

데이터 모델은 일부러 아주 작게 만들었습니다. 어르신을 신선한 폐지로 안내할 만큼만 담고, 그다음엔
잊습니다. 설계서 §3에서 가져왔습니다 — [00-설계서.md](00-설계서.md).

모든 것을 지배하는 두 가지 프라이버시 규칙:
- **공유되는 위치는 대략적이다** — 서버 밖으로 나가기 전에 뭉갠다.
- **안내 세션은 일시적이다** — 오래 저장하지 않으며, 어르신을 추적하지 않는다.

---

## 역할

| 역할 | 하는 일 | 로그인? |
|---|---|---|
| **알리는 사람** (시민 / 가게) | GPS 한 번 탭으로 지점 알림 | 없음 — 익명 |
| **받는 사람** (어르신) | 가장 가까운 지점까지 음성 안내 받음 | 없음, 선택적 가벼운 프로필 |
| **도우미** (가족 / 사회복지사 / 복지관 직원) | 대신 알리거나 어르신 설정을 잡아 줌 | 필요 없음 |
| **관리자 / 모더레이터** | 위험 지점·악용 신고 처리 | 운영자 측 |

알리거나 안내받는 데 로그인이 필요 없습니다. 프로필은 선택이며 최소한만 둡니다.

---

## 엔티티

### `Spot` (지점)
폐지가 나온 한 곳.

| 필드 | 타입 | 설명 |
|---|---|---|
| `id` | id | 지점 식별자 |
| `geoApprox` | 좌표 | **뭉갠** 위치 — 공유되는 유일한 위치 |
| `exactGeoPrivate` | 좌표 | 서버 전용, 공유 전 뭉갬, 다른 사용자에게 **절대 안 보임** |
| `kind` | enum | `paper` · `cardboard` · `mixed` |
| `size` | enum | `small` · `medium` · `large` |
| `note` | text | 선택 짧은 메모 |
| `status` | enum | `open` · `taken` · `gone` · `expired` |
| `reportedAt` | time | 알린 시각 |
| `expiresAt` | time | 자동 만료(기본 4시간, `ONGIGIL_SPOT_TTL_SECONDS`) |
| `reporterRef` | 익명 참조 | 익명 — 이름·얼굴·주소 없음 |

### `GuidanceSession` (안내 세션) *(일시적 — 오래 저장 안 함)*

| 필드 | 타입 | 설명 |
|---|---|---|
| `collectorRef?` | 익명 참조 | 선택 |
| `targetSpotId` | id | 안내 대상 지점 |
| `startedAt` | time | 세션 시작 |
| `lastPos` | 좌표 | 기기에서 **실시간** 사용, 오래 저장 안 함 |
| `events[]` | list | 진행 중 안내 이벤트 |

### `Report` / `Feedback` (피드백)

| 필드 | 타입 | 설명 |
|---|---|---|
| `spotId` | id | 대상 지점 |
| `kind` | enum | `taken`(가져감) · `not_there`(없음) · `report_bad`(부적절 신고) |
| `at` | time | 제출 시각 |

### `User` (사용자) *(선택, 최소)*

| 필드 | 타입 | 설명 |
|---|---|---|
| `id` | id | |
| `role` | enum | 알리는 사람 / 받는 사람 / 도우미 |
| `ageBand?` | enum | 선택, 대략 |
| `prefs` | object | `voiceLang`, `speechRate`, `units` |
| `createdAt` | time | |

## 지점 생애주기

```
   알림 ──► open ─────────────────► taken     (어르신이 "가져갔어요" 표시)
             │  │                   gone      (누군가 "여기 없어요" 신고)
             │  └─────────────────► expired   (expiresAt 지남 — 자동)
             ▼
     geoApprox로만 공유
     (exactGeoPrivate는 서버를 벗어나지 않음)
```

| 상태 | 뜻 | 도달 방법 |
|---|---|---|
| `open` | 살아 있고 수거 가능 | 알림 시 |
| `taken` | 누군가 가져감 | 피드백 `taken` |
| `gone` | 없음 / 이미 치워짐 | 피드백 `not_there` |
| `expired` | 시간 초과 | `expiresAt` 지남(자동) |

**왜 자동 만료?** 길가에 내놓은 폐지는 오래 남지 않습니다. 몇 시간 뒤 지점을 만료시키면, 어르신이 이미
사라진 폐지로 헛걸음하지 않습니다 — 아무도 치우지 않아도 목록이 정직하게 유지됩니다.

---

## 저장하지 *않는* 것

- 어르신이 걸은 경로의 연속 기록(안내 위치는 실시간만).
- 익명 참조를 넘는 알린 사람의 신원.
- 정확한 지점 좌표는 절대 노출 안 함 — 뭉갠 `geoApprox`만.

사용자는 데이터를 내보내고 삭제할 수 있습니다. [04 · 프라이버시와 존엄](04-프라이버시와존엄.md) 참고.
