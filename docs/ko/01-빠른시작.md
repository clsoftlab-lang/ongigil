# 01 · 빠른 시작 — 데모 실행하고 안내 듣기

이 문서는 아무것도 없는 상태에서 **음성 안내를 직접 듣기**까지를 몇 분 안에 안내합니다. 열쇠(API 키)도,
유료 서비스도 필요 없습니다. 두 가지 방법이 있습니다 — 브라우저 데모(가장 빠름)와 실제 백엔드 연결.

---

## A. 브라우저 데모 (백엔드 없음, 열쇠 없음)

앱에는 **데모 모드**가 들어 있습니다 — 미리 넣은 지점과 걷는 흉내(시뮬레이션)로, 전부 브라우저 안에서만
동작하므로 링크 하나로 안내를 듣고 볼 수 있습니다.

1. `app/` 폴더를 HTTP로 띄웁니다 (PWA는 `file://`가 아니라 `http://`가 필요합니다):

   ```bash
   # 저장소 루트에서
   python -m http.server 8150 --directory app
   ```

   어떤 정적 서버든 됩니다 (`npx serve`, nginx 등). 앱은 **빌드 단계가 없고** 외부 CDN도 쓰지 않습니다.
   Claude Code 미리보기(`.claude/launch.json`, 이름 `ongigil-app`, 포트 8150)로도 열 수 있습니다.

2. 폰이나 데스크톱 브라우저에서 **http://localhost:8150/** 을 엽니다.
3. **소리를 켜고** 큰 **"안내 시작"** 버튼을 누릅니다.
4. 데모가 지점 하나를 골라 그쪽으로 **걷는 흉내**를 시작합니다. 다음을 듣고 보게 됩니다:
   - 말로 된 **방향** — 예: "북동쪽";
   - 말하고 마지막엔 **세어 주는 거리** — "50 m … 30 m … 20 m … 앞에 있습니다";
   - 움직임에 따라 **"가까워지고 있어요 / 멀어지고 있어요"**.
5. "도착"하면 **가져갔어요 / 여기 없어요** 표시를 안내받습니다.

> **온라인 버전:** 운영자가 GitHub Pages를 켜면 같은 데모가
> `https://clsoftlab-lang.github.io/ongigil/app/` 에 열립니다 — 이 링크를 공유하면 누구나 들어볼 수 있습니다.

데모 모드는 서버에 접속하지 않고 아무것도 저장하지 않습니다 — 오직 음성을 체험하도록 있습니다.

---

## B. 실제 백엔드에 연결하기

**1. 백엔드 실행 (열쇠 없음):**

```bash
cd backend
pip install -e ".[dev]"
# 진입점은 backend/README.md (채워지는 대로), 예:
uvicorn ongigil.main:app --reload
```

이 API는 작고 상태를 두지 않는 FastAPI 서비스이며 SQLite를 씁니다. 알림/주변/피드백/만료와
`Directions` 인터페이스(호밍 기본, 제공자 스텁)를 제공하고 **열쇠 없이** 동작합니다.

**2. 앱을 이 API로 향하게 하고 앱을 엽니다**(A절처럼 `app/`을 띄웁니다). 알리는 사람은 **"여기 폐지
있어요"**로 GPS 위치에 지점을 저장하고, 받는 사람은 **"안내 시작"**으로 가장 가까운 지점까지 음성 안내를
받습니다.

---

## 확인할 점

- **알림 → 지점:** 한 번 탭으로 대략 위치가 저장됩니다(정확 좌표는 공유 전에 뭉개집니다 —
  [04 · 프라이버시와 존엄](04-프라이버시와존엄.md)).
- **받는 사람 → 음성 반복:** 방향+거리를 움직임에 따라 말하고 반복합니다.
- **신선도:** 지점은 스스로 만료되고, "가져감/없음" 피드백으로 목록이 정직하게 유지됩니다.

---

## 문제 해결

| 증상 | 원인 | 해결 |
|---|---|---|
| 소리가 전혀 안 남 | 탭 전까지 브라우저가 음성 차단 | 먼저 "안내 시작"을 누름(사용자 동작), 기기 음소거 해제 |
| "위치를 알 수 없음" | 위치 권한 거부, 또는 `file://` | 위치 허용, `http://`/`https://`로 열기 |
| 회전 안내 없이 "가까워짐/멀어짐"만 | 나침반(Device Orientation) 없음/미허용 | 정상적인 대체 동작 — [03 · 음성 안내](03-음성안내.md) 참고 |
| 안내 중 화면이 어두워짐 | 해당 브라우저가 Wake Lock 미지원 | 화면을 수동으로 켜 둠 — [06 · 배포와 한계](06-배포와한계.md) |
